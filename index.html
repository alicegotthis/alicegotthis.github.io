CONCEPTUAL EVALUATION WORKFLOW

    Read & prepare

    Load example interactions and criteria from datasets; prepare prompt inputs.

  2. 02
    Request & validate

    Submit to an authorized model API; validate structured responses.

  3. 03
    Compare & report

    Compare prompt versions and generate reports for human review.

Generic tooling: csv/json modules, HTTP clients and spreadsheet libraries. Formats: JSON, CSV and possible XLSX reports. This illustrates a workflow, not private QEA tooling.
