# Engineering in Practice

Presentation companion exploring frontend development, enterprise integration and AI capabilities.

## Edit this site

- `index.html`: page structure and fixed sections.
- `data.js`: four work areas, presentation lines, references and glossary.
- `style.css`: colors, typography and responsive layout.
- `app.js`: chapter switching, presentation mode and copy controls.

Edit files using GitHub’s pencil button, or clone the repository into your editor. Commit changes to `main`; GitHub Pages publishes updates automatically. No build step or package installation is required.

All work descriptions are generalized. Conceptual flows are not production architecture, and platform documentation does not substantiate personal implementation ownership.
